Privacy Policy

Last updated: November 2, 2026

This policy explains what information Leyna Bot stores and how it is used.

1. Information stored

To provide its features, Leyna may store Discord user IDs and the following activity and profile data: message counts, XP, voice activity duration, virtual currency balance, daily reward timestamps, owned profile backgrounds, and the currently selected background.

2. How information is used

This data is used to operate user profiles, rankings, leveling, voice activity features, daily rewards, and the virtual currency system.

3. Storage and retention

Currently, this information is stored by the bot operator in a JSON data file. Leyna does not currently provide an in-bot command for users to delete their stored data. Information may remain stored unless the operator removes it.

4. Sharing

This data is used to operate Leyna. This policy does not promise that data is never disclosed; any disclosure required by law or necessary to protect the service will be handled as applicable.

5. Security

The operator should take reasonable steps to protect the data file and limit access to it. No storage method can be guaranteed completely secure.

6. Contact

For questions or requests about stored data, contact the Leyna developer through the bot's official support server. A user-facing deletion feature is not currently available.
